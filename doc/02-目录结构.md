# 02 - 目录结构

## 2.1 顶层目录总览

```
rosrobotcontrollerm4_motor_ps2/
├── Core/                    # STM32CubeMX 生成的核心代码
├── Drivers/                 # ST CMSIS + HAL 驱动库
├── Middlewares/             # FreeRTOS、USB Host 中间件
├── Third_Party/             # 第三方开源库
├── Hiwonder/                # ★ 幻尔业务代码（主要开发目录）
├── USB_HOST/                # USB Host 应用与配置
├── MDK-ARM/                 # Keil 工程与编译输出
├── doc/                     # 项目文档（本目录）
├── RRC升级脚本_通用例程/     # 升级/移植参考脚本与示例
├── SI/                      # Source Insight 工程（可选）
├── RosRobotControllerM4.ioc # CubeMX 配置
├── README.md
├── Doxyfile
└── ros_robot_controller_m4.jflash
```

---

## 2.2 Core/ — CubeMX 生成代码

```
Core/
├── Inc/                     # 头文件
│   ├── main.h, gpio.h, tim.h, usart.h, spi.h, i2c.h, adc.h, dma.h, crc.h
│   ├── FreeRTOSConfig.h
│   └── stm32f4xx_hal_conf.h, stm32f4xx_it.h
└── Src/
    ├── main.c               # 程序入口，调用 MX_FREERTOS_Init()
    ├── freertos.c           # RTOS 任务/队列/定时器/信号量定义
    ├── stm32f4xx_it.c       # 中断服务
    ├── stm32f4xx_hal_msp.c  # 外设 MSP 初始化
    ├── gpio.c, tim.c, usart.c, spi.c, i2c.c, adc.c, dma.c, crc.c
    ├── system_stm32f4xx.c
    ├── syscalls.c, sysmem.c
    └── Backup/              # CubeMX 备份（可忽略）
```

**职责**：时钟、GPIO、定时器、串口、DMA 等底层初始化；**不包含**业务逻辑。

---

## 2.3 Hiwonder/ — 业务代码（核心）

```
Hiwonder/
├── System/                  # 系统级应用与全局配置
├── Chassis/                 # 底盘运动学
├── Peripherals/             # 外设对象封装（电机、IMU、显示等）
├── Portings/                # 硬件/RTOS 移植层
├── Misc/                    # 协议、PID、日志、校验等工具
├── LVGL_UI/                 # LVGL 界面（Guider 生成）
└── USB_HOST/                # 手柄 HID 扩展
```

### System/

| 文件 | 说明 |
|------|------|
| `app.c` | **用户主任务** `app_task_entry()`，底盘与手柄控制 |
| `gampad_handle.c` | USB 手柄 HID 回调，向运动队列发消息 |
| `gui_handle.c` | GUI 任务 `gui_task_entry()` |
| `battery_handle.c` | 电池检测定时器回调 |
| `global.h` / `global_conf.h` | 全局头文件与功能开关宏 |
| `checksum.c` | 校验辅助 |

### Chassis/

| 文件 | 说明 |
|------|------|
| `chassis.h` | 底盘类型枚举与统一接口 `ChassisTypeDef` |
| `differential_chassis.c/.h` | 差速底盘（履带、坦克、四轮差速） |
| `mecanum_chassis.c/.h` | 麦克纳姆全向 |
| `ackermann_chassis.c/.h` | 阿克曼转向 |

**底盘类型枚举**（`chassis.h`）：

| 枚举值 | 适用车型 |
|--------|----------|
| `CHASSIS_TYPE_JETTANK` | JetTank |
| `CHASSIS_TYPE_TANKBLACK` | 黑色履带（**本工程使用**） |
| `CHASSIS_TYPE_TI4WD` | 四轮差速 |
| `CHASSIS_TYPE_JETAUTO` | JetAuto（麦克纳姆） |
| `CHASSIS_TYPE_JETACKER` | JetAcker（阿克曼） |

### Peripherals/

| 模块 | 文件 | 说明 |
|------|------|------|
| 编码器电机 | `encoder_motor.c/.h` | 带 PID 的速度闭环 |
| IMU | `QMI8658.c`, `imu_mpu6050.c`, `imu.h` | 惯性测量 |
| 显示 | `display_st7735.c`, `display.h` | ST7735 LCD |
| 舵机 | `pwm_servo.c`, `serial_servo.c` | PWM / 总线舵机 |
| 人机 | `button.c`, `led.c`, `buzzer.c`, `key.c` | 按键、灯、蜂鸣器 |

### Portings/

将抽象外设绑定到具体 GPIO/TIM/UART/DMA，并实现 RTOS 任务入口：

| 文件 | 绑定内容 |
|------|----------|
| `motor_porting.c` | 4 路电机 TIM + 编码器 |
| `chassis_porting.c` | 底盘实例化与 `set_chassis_type()` |
| `imu_porting.c` | `imu_task_entry()` |
| `packet_porting.c` | 串口协议 DMA + 收发任务 |
| `bluetooth_porting.c` | `bluetooth_task_entry()` |
| `sbus_porting.c` | SBUS 接收 |
| `lcd_porting.c` / `u8g2_porting.c` | 显示驱动 |
| `pwm_servo_porting.c` / `serial_servo_porting.c` | 舵机 |
| `button_porting.c` / `led_porting.c` / `buzzer_porting.c` | 板载 IO |
| `lwmem_porting.c` | 动态内存池 |
| `motors_param.h` | 电机 PID 与机械参数 |

### Misc/

| 文件 | 说明 |
|------|------|
| `packet.c` / `packet.h` | 上位机通信协议解析 |
| `pid.c` / `pid.h` | PID 控制器 |
| `log.c` / `log.h` | 日志（UART 或 SEGGER RTT） |
| `sbus.c` / `sbus.h` | SBUS 协议 |
| `checksum.c` | 数据校验 |
| `object.h` | 对象类型 ID |

### LVGL_UI/

由 **NXP GUI Guider** 生成的界面资源：

- `gui_guider.c/.h` — 界面总控
- `setup_scr_screen_*.c` — 各屏幕（startup、ps2、imu、sbus、sys 等）
- `events_init.c` — 事件绑定
- `custom.c` — 用户自定义 UI 逻辑
- `guider_fonts/` — 思源黑体等字体
- `images/` — 图片资源

### USB_HOST/（Hiwonder 扩展）

| 文件 | 说明 |
|------|------|
| `usbh_hiwonder_hid.c` | 幻尔 HID 设备支持 |
| `usbh_hid_gamepad.c/.h` | 游戏手柄数据结构解析 |

## 2.4 Drivers/

```
Drivers/
├── CMSIS/                   # ARM CMSIS 核心与设备头文件
│   ├── Device/ST/STM32F4xx/
│   └── Include/
└── STM32F4xx_HAL_Driver/    # ST HAL 库源码
    ├── Inc/
    └── Src/
```

ST 官方驱动，一般无需修改。

---

## 2.5 Middlewares/

```
Middlewares/
├── Third_Party/
│   └── FreeRTOS/            # FreeRTOS 内核 + CMSIS-RTOS v2 适配
└── ST/
    └── STM32_USB_Host_Library/   # USB Host 核心 + HID 类
        ├── Core/
        └── Class/HID/
```

---

## 2.6 Third_Party/

| 目录 | 库 | 用途 |
|------|-----|------|
| `LVGL/` | LittlevGL | 图形界面（`ENABLE_LVGL` 控制） |
| `U8g2/` | u8g2 | 轻量显示（备用方案） |
| `Lw/` | lwmem, lwrb, lwpkt, lwshell | 内存池、环形缓冲、协议、Shell |
| `RTT/` | SEGGER RTT | 调试输出（J-Link） |
| `Fusion/` | Fusion AHRS | IMU 姿态融合算法 |

`Third_Party/LVGL/porting/` 含 `lv_port_disp.c`、`lv_port_indev.c` 等显示/输入移植。

---

USB_HOST/

## 2.9 RRC升级脚本_通用例程/

升级与模块移植的参考包，包含：

- `选择性移植文件/` — 可单独拷贝的 `packet_porting.c`、`imu_porting.c` 等
- `履带底盘（坦克）/` — 履带相关配置
- `GCC/` — GCC 工具链相关（若有）

用于从通用 RRC 固件向特定车型迁移时的对照参考。

---

## 2.10 SI/

Source Insight 4 工程文件（`Tank_DiPan.si4project`），用于代码浏览，不影响编译。

---

## 2.11 不应纳入版本管理的目录

编译与 IDE 产生物通常已在 `.gitignore` 中：

- `MDK-ARM/RosRobotControllerM4/`（对象文件与 hex）
- `*.uvguix.*`（Keil 用户界面状态）
- `JLinkLog.txt`
