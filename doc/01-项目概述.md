# 01 - 项目概述

## 1.1 项目简介

**RosRobotControllerM4** 是幻尔（Hiwonder）ROS 机器人控制板 M4 的 STM32 固件工程。本仓库变体面向 **悬挂履带底盘**，通过 **USB Host** 连接 **PS2 兼容手柄** 进行遥控，同时支持串口通信协议、蓝牙、SBUS、IMU、LCD 显示等扩展能力。

工程基于 ST 官方 **STM32CubeMX** 生成 HAL 与 FreeRTOS 骨架，业务逻辑集中在 `Hiwonder/` 目录，与 ST 生成代码通过 `USER CODE` 注释块隔离，便于 CubeMX 重新生成时不覆盖用户代码。

## 1.2 硬件平台

| 项目 | 说明 |
|------|------|
| 主控芯片 | STM32F407VET6（Cortex-M4，512KB Flash，192KB RAM） |
| 系统时钟 | 由 `SystemClock_Config()` 配置（见 `Core/Src/main.c`） |
| 通信外设 | USART（调试/协议/蓝牙）、I2C（IMU）、SPI（LCD）、USB OTG FS（手柄 Host） |
| 执行机构 | 4 路编码器电机、PWM 舵机、总线舵机、蜂鸣器、LED、按键 |

## 1.3 主要功能

### 运动控制

- 支持多种底盘运动学模型（差速、麦克纳姆、阿克曼等），通过 `set_chassis_type()` 切换
- **本工程默认**：`CHASSIS_TYPE_TANKBLACK`（黑色履带，差速模型）
- 统一底盘 API：`set_velocity()`、`set_velocity_radius()`、`stop()`

### 遥控输入

- **PS2/USB 手柄**：`Hiwonder/System/gampad_handle.c` 中 `USBH_HID_EventCallback()` 解析 HID 数据，向 `moving_ctrl_queue` 投递控制字符
- **SBUS 遥控器**：独立任务 `sbus_rx_task`（实现见 `Hiwonder/Portings/sbus_porting.c`）
- **串口协议**：帧格式 `0xAA 0x55` + 功能码 + 数据 + 校验（`Hiwonder/Misc/packet.c`）

### 传感与人机

- IMU（QMI8658 / MPU6050 等，由移植层选择）
- 1.8 寸 ST7735 LCD + LVGL / U8g2 双显示方案（由宏开关）
- 电池电压监测与低电量报警（可配置）

### 上位机 / ROS 通信

- 串口 Packet 协议，功能码包括电机、舵机、IMU、手柄状态、SBUS 等
- 蓝牙透传（`bluetooth_task`，`Hiwonder/Portings/bluetooth_porting.c`）

## 1.4 软件栈

```
应用层     Hiwonder/System, Chassis, LVGL_UI
    ↓
移植层     Hiwonder/Portings/*_porting.c
    ↓
驱动抽象   Hiwonder/Peripherals, Misc
    ↓
HAL/Cube   Core/, Drivers/, USB_HOST/
    ↓
RTOS       Middlewares/FreeRTOS
    ↓
第三方库   Third_Party/ (LVGL, U8g2, LwMEM, SEGGER RTT, Fusion...)
```

## 1.5 程序入口说明

| 层级 | 文件 | 函数 | 说明 |
|------|------|------|------|
| 芯片入口 | `Core/Src/main.c` | `main()` | HAL 初始化、外设初始化、启动调度器 |
| RTOS 默认任务 | `Core/Src/freertos.c` | `StartDefaultTask()` | 初始化 USB Host |
| **用户主逻辑** | `Hiwonder/System/app.c` | `app_task_entry()` | 电机/底盘/手柄控制主循环 |

> **注意**：在 `app_task_entry()` 的 `for(;;)` 循环中必须使用 `osDelay()` 或其他阻塞 API，否则会导致看门狗/调度异常。

## 1.6 与本教程包的关系

本源码位于教程目录 **「悬挂履带底盘 → STM32 版本 → 源码程序」** 下，工程名 `rosrobotcontrollerm4_motor_ps2` 表明侧重 **电机驱动 + PS2 手柄** 控制场景。配套还有 `RRC升级脚本_通用例程/` 目录，提供选择性移植的参考文件。
