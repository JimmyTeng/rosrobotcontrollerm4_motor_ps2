# 04 - 开发指南

## 4.1 开发环境

| 工具 | 版本建议 | 用途 |
|------|----------|------|
| Keil MDK-ARM | v5.x | 编译、调试、烧录 |
| STM32CubeMX | 与 `.ioc` 匹配 | 修改引脚/时钟/RTOS（可选） |
| ST-Link / J-Link | — | 下载与调试 |
| STM32CubeProgrammer | — | 批量烧录（`.hex`） |

**打开工程**：`MDK-ARM/RosRobotControllerM4.uvprojx`

**目标器件**：STM32F407VETx

**预定义宏**（工程已配置）：

```
USE_HAL_DRIVER, STM32F407xx, LV_CONF_INCLUDE_SIMPLE, LV_LVGL_H_INCLUDE_SIMPLE
```

---

## 4.2 编译与烧录

1. 用 Keil 打开 `RosRobotControllerM4.uvprojx`
2. 选择 Target → Build（F7）
3. 成功后在 `MDK-ARM/RosRobotControllerM4/` 生成 `RosRobotControllerM4.hex`
4. 使用 ST-Link / J-Link 下载，或使用 `ros_robot_controller_m4.jflash` 配置

---

## 4.3 二次开发入口

### 修改运动/手柄逻辑

**首选文件**：`Hiwonder/System/app.c`

- `app_task_entry()` — 初始化顺序、主循环
- `ti4wd_control(char msg)` — 各按键对应的运动/舵机动作
- 速度范围建议：`50 ~ 450`（`speed` 变量）

### 切换底盘类型

在 `app.c` 的 `chassis_init()` 之后：

```c
set_chassis_type(CHASSIS_TYPE_TANKBLACK);  // 黑色履带
// set_chassis_type(CHASSIS_TYPE_TI4WD);   // 四轮差速
// set_chassis_type(CHASSIS_TYPE_JETAUTO); // 麦克纳姆
```

### 调整电机 PID / 机械参数

- 电机 PID：`Hiwonder/Portings/motors_param.h`
- 轮径/轮距：`Hiwonder/Chassis/chassis.h` 中对应 `*_WHEEL_DIAMETER`、`*_SHAFT_LENGTH`

### 功能开关

编辑 `Hiwonder/System/global_conf.h` 中的 `ENABLE_*` 宏。

### 新增 FreeRTOS 任务

**推荐流程**：

1. 在 STM32CubeMX 的 FREERTOS 选项卡中添加 Task
2. 重新生成代码
3. 在 `Hiwonder/` 下实现任务函数（覆盖 weak 桩）
4. 用户代码写在 `/* USER CODE BEGIN */` … `/* USER CODE END */` 之间

### CubeMX 用户代码保护区

修改 Cube 生成文件时，**必须**写在以下注释块内，否则重新生成会被覆盖：

```c
/* USER CODE BEGIN xxx */
// 你的代码
/* USER CODE END xxx */
```

## 4.4 调试方法

### 串口日志

`global_conf.h` 中 `ENABLE_DEBUG_UART = 1` 时，使用 `printf` / `LOG_*` 宏输出到调试串口。

### SEGGER RTT

设置 `ENABLE_DEBUG_UART = 0`，通过 J-Link RTT Viewer 查看 `Third_Party/RTT/` 输出。

### 常见注意点

1. **任务循环必须有 `osDelay`**，否则低优先级任务饿死
2. **USB 手柄** 需在 `defaultTask` 完成 `MX_USB_HOST_Init()` 后插入
3. 当前 `app.c` 内含上电自检运动代码（前进/后退/旋转），量产前建议删除或加宏控制
4. 串口协议任务若需启用，检查 `packet_porting.c` 函数名与 `freertos.c` 任务入口是否一致

## 4.7 与 ROS / 上位机联调

1. 通过板载 USART 连接 PC，波特率以 CubeMX `usart.c` 配置为准
2. 使用 Packet 协议（`0xAA 0x55` 帧头）发送 `PACKET_FUNC_MOTOR` 等命令
3. 可同时开启蓝牙透传，由 `bluetooth_task` 转发
4. 手柄控制与串口控制共用底盘 API，注意互斥与优先级设计
